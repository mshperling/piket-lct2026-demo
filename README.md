# Пикет

Публичный прототип команды **Бананчики** для ЛЦТ 2026. Рабочее место диспетчера для превентивных проверок инженерных коллекторов.

[Открыть рабочее место](https://mshperling.github.io/piket-lct2026-demo/app/) · [Документация](DOCUMENTATION.md) · [Карточка модели](MODEL_CARD.md) · [Презентация PDF](PIKET_LCT2026.pdf) · [PowerPoint](PIKET_LCT2026.pptx)

В интерфейсе показан реальный исторический срез на **29 марта 2026 года**: 26 групп, сохранённые прогнозы, история эпизодов и черновик проверки группы 553-1. Решения и комментарии сохраняются только в браузере пользователя. Публичный прототип не отправляет задания бригадам и не подключён к действующей инфраструктуре.

## Открыть локально

```sh
python3 -m http.server 8080
```

Затем открыть http://localhost:8080/ . Сайт не требует сборки, серверных зависимостей или ключей.

## Данные и оценка

`app/replay-data.json` содержит агрегированный архивный срез. `app/evaluation.json` содержит отдельный результат исторической оценки. Прогнозируются диагностические события СМВУ, а не подтверждённые актами ремонта поломки. Подробности протокола и ограничения указаны в карточке модели.

[Репозиторий полного решения](https://github.com/Valle-ds/lct2026-moskollektor) доступен участникам проекта. Здесь опубликован самостоятельный клиентский прототип и материалы защиты.
